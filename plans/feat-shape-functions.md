# feat: 分布の形と平均の関数を足す（#98 の 3 のうち 1 つの範囲で決まるもの）

## 足すもの

`SKEW`・`KURT`・`STANDARDIZE`・`PERCENTRANK.INC`（別名 `PERCENTRANK`）・`GEOMEAN`・`HARMEAN`。#98 の 2（回帰と予測）と `MAXIFS`/`MINIFS` は、範囲の読み方を変える #104 のあとにする。

## 作り

- `shape-math.ts`（純粋な関数）：Excel の式（`SKEW` は n / ((n−1)(n−2)) Σz³、`KURT` は過剰尖度の標本の式）と、Excel と同じ誤り
- `shape.ts`：引数を `SUM` と同じ読み方で数に集め（数の無いセルは飛ばす）、登録する
- `PERCENTRANK.INC` は、x がデータに無ければ前後の値で補い、有効桁（既定 3）で切り捨てる。最大値が重なるときは 1 にならない（Excel も `{1,2,2}` の 2 を 0.5 にする）

## 確かめたこと

- Microsoft の計算例
- 式に頼らない性質（種を表示する。`SHAPE_SEED`）：ずらしても拡大しても `SKEW`・`KURT` は変わらない、調和平均 ≤ 幾何平均 ≤ 算術平均、`PERCENTRANK` は最小で 0、最大で「最大より小さい値の数 ÷ (n−1)」、単調に増える
- 引数の決まり（`#DIV/0!`・`#NUM!`・`#N/A`、誤りの引数がそのまま返る）
- 実装をわざと壊すと、テストが落ちる
