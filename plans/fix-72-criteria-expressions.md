# 条件の引数を式として計算する（#72）

`COUNTIF` `SUMIF` `AVERAGEIF` `COUNTIFS` `SUMIFS` `AVERAGEIFS` の条件を、書いた文字のまま読んでいた。そのため、`C1` や `">="&C1` は何にも合わず、黙って 0 になっていた。

- `criteriaArg`（`registry.ts`）：条件の引数を `evaluateFormula` で計算してから `parseCriteria` に渡す。計算がエラーなら、そのエラーを返す。
- 六つの関数はすべて `criteriaArg` を通す。

## 確かめたこと

- `tests/engine/test_criteriaExpressions.ts`：セル参照、`&` でつないだ条件、文字の条件、エラーの伝わり方。直しを外すと、セル参照と `&` とエラーの組が落ちる。
- 文字で書いた条件の答えが変わらないこと：公開済みの 4.1.0 とこのブランチに、六つの関数・生成した条件と表を食わせて比べた。二つの種で一致した。

## 見つけた別の不具合

`&` を `+` より先に計算している（#75）。`"<"&C1+1` は Excel と違う値になる。この PR では直さない。
