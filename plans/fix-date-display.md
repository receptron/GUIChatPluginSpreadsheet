# fix: 書式の無い計算式の結果を、出どころが日付のときだけ日付として出す (#106)

## 決めたこと

issue の「決めること」は推奨の**案 A**。

- 日付として出すのは、今までの範囲（36000〜63499 の整数）に入り、かつ次のどちらかに当たるときだけ
  - 式が日付を返す関数で始まる（`DATE` `TODAY` `EDATE` `EOMONTH` `WORKDAY`。括弧と符号は飛ばす。`=DATE(…)+1` も含む）
  - 式の最初の参照（範囲なら先頭）が日付：日付の書式を持つ、日付として入力された、または自分も日付を出す式
- 「どこまでたどるか」：最初の参照が式なら、その式もたどる（何段でも。循環は止める）。別のシートのセルも、そのシートの書式と式で判定する
- `NOW` は時刻を持つので入れない

## 範囲外と変わる見た目

- 日付を引く `HLOOKUP` / `VLOOKUP` などの答えは、書式が無ければ数で出る（Excel も同じ）。fixture `date.json` の期待値を `03/15/2025` から `45731` に直した
- 日付どうしの差（`=A1-A2`）は、範囲の外なので数のまま（Excel は `1/31/1900` のような日付で出す）

## 確かめたこと

- `leadingCall` と `formulaShowsDate` の例（先頭の関数、最初の参照の書式、たどる、循環、別のシート、`$`、文字の中の `DATE(`、先頭が `IF`）
- エンジンを通した例（issue の表、日付の関数と日付の参照、明示した書式、引いた日付）
- 古い実装と並べて、作った式で比べた。差はすべて「前は日付、今は数」で、新しく日付になった式は無い
- 実装をわざと壊すと、テストが落ちる
