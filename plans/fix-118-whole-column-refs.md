# fix: 列全体・行全体の参照を読む（#118）

## 原因

`A:A`・`1:1` は、どの読み方でも参照として見分けられていなかった。範囲の展開（`expandRangeOrCell`）は `A1` の形しか受け取らない。集計の引数を見分ける `isRangeReference` も同じで、`A:A` は値として評価され、0 になっていた。

## 直したこと

式を評価する前に、列全体・行全体の参照を、そのシートのデータのある範囲に書き換える（`src/engine/wholeReferences.ts` の `boundWholeReferences`。純粋な関数）。

- `A:A` は `A1:A<最後の行>`、`1:1` は `A1:<最も長い行の最後の列>1` になる
- シート名の付いた参照（`Data!A:A`、`'My Sheet'!A:A`）は、そのシートのデータで決める。無いシートは書き換えない
- 文字列の中（`"A:A"`）は書き換えない
- `$` は外す。小文字も読む。逆向き（`C:A`、`5:2`）は並べ直す
- 形の崩れた参照（`A:B1` など）は書き換えない

書き換えは `calculator.ts` の `resolveFormulaCell` の一か所だけ。範囲・参照の関数・引数の見分けは、どれも普通の `A1:B2` を受け取る。データの外は #115（#120）で空のセルとして読むので、答えは Excel と同じになる。

## 対象外

- 画面で参照先のセルを色付けする `extractCellReferences`（View.vue）は、`A:A` を色付けしない
- プラグインの API の範囲の読み取り（`src/core/rangeValues.ts`）は、今の `A1:B2` の形のまま

## テスト（`tests/engine/test_wholeReferences.ts`）

- 書き換えの例：列・行、`$`、小文字、逆向き、シート名、空のシート、文字列の中、形の崩れた参照
- 生成した式で、列全体・行全体を含まない式は、書いたとおりのまま残る（種を表示する。`WHOLE_REFERENCES_SEED`）
- 生成したシートで、`A:A` などを使った式と、同じ範囲を手で書いた式が、同じ答えになる
- 実装をわざと壊すと、テストが落ちる
